Challenge

Monocular teleoperation obscures the 3D precision required for functional grasping.

In monocular teleoperation, operators see the remote scene through a flat video feed and can convey only coarse hand and palm motion. Dexterous grasping still requires precise 3D hand–object relationships and task-appropriate contacts.

The result is a mismatch: the operator knows what the object should be used for, but cannot directly specify how every finger should make contact.

Human input Coarse, semantic
→
Robot requirement Precise, contact-rich
Approach

Let the operator choose the intent. Let the robot solve the details.

From a single RGB-D view, our system builds a library of functional human-hand grasps and learns the palm-pose distribution for each grasp type. It predicts intent as the operator moves, overlays the result for verification, then converts the confirmed reference into an Allegro Hand trajectory.
